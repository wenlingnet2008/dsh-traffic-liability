# 道路交通事故认定复核申请书模板

`道路交通事故认定复核申请书模板.docx` 为插件独立编写的可编辑空白模板；对应 `.txt` 保留相同正文。填写所有“【待补充：…】”后，结合实际证据修改理由，由本人签署并提交。它是申请书模板，不是公安机关出具的复核结论书，也不是全国统一官方表格。

结构参考：[律师教你怎么做《道路交通事故认定复核申请书（范本）》](https://wjorg.com/template/jiaotong-fuhe-shenqing)。该来源为一般法律知识分享，仅供参考，不构成正式法律意见。本插件独立撰写措辞，未照搬范本中的“撤销或变更”、自动认定按时提交等表述。

程序依据：[深圳市公安局交通管理局公开的《道路交通事故处理程序规定》（公安部令第146号）](https://szjj.sz.gov.cn/ZWGK/ZCFG/ZCFKS/JTSGYW/content/post_4458457.html)。第七十一条要求请求、理由和主要证据，并规定送达之日起三日内、同一事故复核一次；第一百一十二条规定“三日”指工作日，不包括节假日；第七十二条允许经原认定机关或直接向上一级公安机关交通管理部门提出；第七十六条规定责令原办案单位重新调查、认定的情形。

申请期限很短，应及时核实送达时间、提交方式及既往复核情况。本模板不计算节假日调休后的截止日期，不代签或提交。

重建模板及生成短、长中文视觉校验样例：

```sh
node --import tsx scripts/render-review-samples.ts /tmp/traffic-review-visual-qa
```

样例使用虚构数据，供渲染检查，不作为真实案件文书。模板和实际案件导出使用同一生成器；Word 为可编辑文字，签名区留空。
